# 🍽️ Restaurant Management System

A simple and beginner-friendly **Restaurant Management System** built using Python. It helps customers place food orders, calculate bills, and get discounts automatically. 🧾

## ✨ Features

- 📋 Display Food Menu
- 🛒 Place Food Orders
- 🔢 Select Item Quantities
- 💰 Automatic Bill Calculation
- 🎉 Discount Calculation
- 🧾 Generate Final Bill
- 👤 Customer Name Input

## 🍕 Available Menu

| Item | Price |
|---|---:|
| Pizza 🍕 | ₹250 |
| Burger 🍔 | ₹120 |
| Pasta 🍝 | ₹180 |
| Momos 🥟 | ₹100 |
| Cold Drink 🥤 | ₹50 |

## 💸 Discount System

- 5% Discount on orders above ₹500.
- 10% Discount on orders above ₹1000.

- 💻 VS Code
